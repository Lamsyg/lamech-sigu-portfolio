# Lamech Odhiambo Sigu — Portfolio

A responsive personal landing page and technical portfolio built with Next.js, React and Tailwind CSS.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open http://localhost:3000.

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `app/page.js` with your professional email.
- Add your LinkedIn and GitHub profile links.
- Add a downloadable CV in the `public` folder and link it from the hero section.
- Add project screenshots only after removing patient information, IP addresses, hostnames, credentials and other confidential details.
- Review every project description to ensure it accurately reflects your role and contribution.

## Deploy

Push the project to GitHub, then import the repository into Vercel. Connect your own domain through the Vercel project settings.
